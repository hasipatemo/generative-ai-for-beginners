# 📱 まいにちタスク 操作マニュアル

このアプリは「毎日やりたいこと（タスク）」ができたかどうかを記録して、
カレンダーでふり返ったり、AIからコメントをもらったりできるアプリです。

---

## 1. 画面の見方

<img src="../images/record.png" width="260" align="right">

画面は大きく3つの部分に分かれています。

**① 上のタブ（グループ）**
「ヘルス管理」「宿題・塾」「家事」のような、タスクのまとまりです。
タップすると、そのグループのタスクに切り替わります。
（選んだグループは色が付きます。次に開いたときも同じグループが表示されます）

**② まんなか（メインの画面）**
下のメニューで選んだ画面が表示されます。

**③ 下のメニュー**
| ボタン | できること |
|---|---|
| 📝 きろく | その日のタスクの状況を記録する |
| 📅 カレンダー | 1か月の状況をふり返る |
| ⚙️ せってい | グループやタスクを追加・変更・削除する |

## 2. まずは準備（せってい）

<img src="../images/settings.png" width="260" align="right">

はじめて開いたときは、サンプルのグループとタスクが入っています。
自分に合わせて変えてみましょう。

### グループを作る
1. 下のメニューの **⚙️ せってい** をタップ
2. 「グループ」の入力欄に名前（例：`ヘルス管理`）を入れて **追加**
3. 追加したグループが、上のタブに表示されます

### グループの名前を変える・削除する
- **✏️** … 名前を変更します
- **🗑** … グループを削除します
  ⚠️ グループを削除すると、その中の **タスク・記録・AIコメントもすべて消えます**。

### タスクを追加する
1. 上のタブ、または「グループ」一覧の名前をタップして、タスクを追加したいグループを選ぶ
2. 「〇〇のタスク」の入力欄に名前（例：`ストレッチ10分`）を入れて **追加**
3. タスクは **1つのグループにつき10個まで** です。
   10個になると入力欄が使えなくなります。追加したいときは、どれかを削除してください。

### タスクの名前を変える・削除する
- **✏️** … 名前を変更します（これまでの記録はそのまま残ります）
- **🗑** … タスクを削除します
  ⚠️ そのタスクの **過去の記録も消えます**。

## 3. 毎日の記録（きろく）

### 記録する（登録）
1. 下のメニューの **📝 きろく** をタップ
2. 上のタブで記録したいグループを選ぶ
3. タスクごとに、次の3つから1つをタップ

| ボタン | 意味 |
|---|---|
| ✅ やった | 全部できた |
| 🔺 半分できた | 途中まで・少しだけできた |
| ❌ やってない | できなかった |

4. 最後に **💾 保存する** をタップ → 「保存しました」と表示されたら完了です。

> 💡 同じボタンをもう一度タップすると、選択が取り消されて「未記録」に戻ります。
> 💡 保存していない変更があると「● 変更があります」と表示されます。
> そのまま別の日や画面に移動しようとすると「保存せずに移動しますか？」と確認されます。

### 日付を変える
- **◀ / ▶** … 前の日・次の日へ
- **まんなかの日付をタップ** … カレンダーから日付を選べます
- 今日の日付には「今日」マークが付きます
- 過去の日の記録をあとから付けることもできます

### 記録を直す（修正）
その日を開いて、ボタンを押しなおして **💾 保存する** を押すだけです。

### 記録を消す（削除）
その日を開いて **🗑 削除** をタップ →「削除する」を押すと、
その日のそのグループの記録（とAIコメント）がすべて消えます。

### 達成度について
画面上の「この日の達成度」は、次の計算で出しています。

```
達成度 ＝（やった の数 × 1 ＋ 半分できた の数 × 0.5）÷ タスクの数
```

例）タスク4個のうち「やった」1個・「半分」1個 → (1 + 0.5) ÷ 4 = 38%

## 4. AIからコメントをもらう

<img src="../images/ai-comment.png" width="260" align="right">

1. きろく画面のいちばん下の **🤖 AIからのコメント** の **コメントをもらう** をタップ
2. 数秒待つと、その日の記録と **直近7日間の傾向** を見て、AIがコメントしてくれます
   - できたことをほめてくれる
   - できなかったことには、明日から試せる小さな工夫を1つ提案してくれる
3. コメントは保存されるので、あとでその日を開いたときにも表示されます
4. 記録を直したあとは **もう一度** を押すと、新しいコメントに更新されます

> 💡 保存していない変更がある場合は、自動で保存してからコメントを作ります。
> 💡 AIのAPIキーが設定されていない場合は、決まったルールで作る「自動メッセージ」が表示されます（設定方法は README をご覧ください）。

## 5. カレンダーでふり返る

<img src="../images/calendar.png" width="260" align="right">

1. 下のメニューの **📅 カレンダー** をタップ
2. 選んでいるグループの1か月分の状況が、色で表示されます

| 色 | 意味 |
|---|---|
| 🟩 みどり | 達成度 80%以上 |
| 🟨 きいろ | 50%以上 |
| 🟧 オレンジ | 1〜49% |
| 🟥 あか | 0%（記録したけど全部できなかった） |
| ⬜ しろ | 未記録 |

- 日付の下の小さな棒は、✅（緑）🔺（黄）❌（赤）の割合です
- 青い枠は「今日」、黒い枠は「きろく画面で選んでいる日」です
- **日付をタップ** すると、その日の「きろく」画面が開きます（あとから記録・修正ができます）
- **◀ / ▶** で前の月・次の月に移動します

### 月のまとめ
カレンダーの下に、その月の
- 記録した日数
- 平均達成度
- ✅ やった回数
- タスクごとの ✅🔺❌ の回数と割合（どのタスクが続いているか・苦手か）

が表示されます。

## 6. スプレッドシートで見る

記録はすべて、元のスプレッドシートに保存されています。

| シート名 | 保存されている内容 |
|---|---|
| グループ | グループの名前と色 |
| タスク | タスクの名前・どのグループか・並び順 |
| 記録 | 日付・タスク・状況（done=やった／half=半分／none=やってない） |
| AIコメント | 日付・グループ・AIのコメント |

> ⚠️ スプレッドシートを直接書きかえると、アプリが正しく動かなくなることがあります。
> 特に「ID」の列や見出し（1行目）は変更しないでください。変更はアプリの画面から行うのが安全です。

## 7. こまったときは

| こまりごと | 対処法 |
|---|---|
| 画面が真っ白・読み込まない | ページを再読み込みしてください。直らない場合は、URLが最新のデプロイのものか確認してください |
| 「⚠️」のメッセージが出た | 書かれている内容を確認してください（例：タスクは10個まで など） |
| AIコメントが「自動メッセージ」になる | APIキーが未設定か、キーが間違っています。README の「AIのAPIキーを設定する」を確認してください |
| 日付が1日ずれる | スプレッドシートの「ファイル → 設定 → タイムゾーン」を「(GMT+09:00) 東京」にしてください |
| タスクが追加できない | そのグループのタスクが10個に達しています。どれかを削除してください |
